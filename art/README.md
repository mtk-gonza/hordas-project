# Recursos de arte

Los mapas jugables se eligen en el lobby. Sus fondos (`neon_city_arena.png`, `biosynth_garden_arena.png` y `orbital_foundry_arena.png`) son originales creados para este proyecto y se integran desde `art/processed/`; consulta `ASSET_CREDITS.md`.

Los originales del paquete se conservan en `art/external/pixel_crawler/Pixel Crawler - Free Pack/`; las hojas que consume el juego están agrupadas bajo `art/external/pixel_crawler/game/`. Los recortes y composiciones adaptadas van en `art/processed/`; `swarm_arena.png` se regenera con `tools/generate_swarm_arena.py`. La licencia del autor permite usar el arte en proyectos comerciales, pero prohíbe venderlo como producto artístico independiente. Consulta [ASSET_CREDITS.md](ASSET_CREDITS.md) y conserva `Terms.txt` junto a cualquier redistribución del juego.
